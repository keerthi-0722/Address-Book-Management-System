# Address Book Management System

## 📌 Project Description

The **Address Book Management System** is a console-based application developed using C++ that allows users to efficiently store, manage, search, and delete contact information. It provides a simple menu-driven interface to perform basic contact management operations.

This project demonstrates fundamental C++ programming concepts such as structures, arrays, functions, loops, conditional statements, and string handling.

## 🎯 Objectives

- To develop a simple and efficient contact management system.
- To perform basic CRUD operations on contact details.
- To understand the practical implementation of C++ programming concepts.
- To provide an easy-to-use menu-driven interface.

## ✨ Features

- **Add Contact:** Store a new contact with name, phone number, email, and address.
- **Display Contacts:** View all saved contact details.
- **Search Contact:** Find contacts using their names.
- **Delete Contact:** Remove unwanted contacts from the address book.
- **Menu-Driven Interface:** Navigate through different operations easily.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Structures, Arrays, Functions, Loops, Conditional Statements, String Handling
- **Compiler:** GCC / MinGW / Any C++ Compatible Compiler

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone <your-repository-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd Address-Book-System
   ```

3. Compile the program:

   ```bash
   g++ main.cpp -o addressbook
   ```

4. Run the application:

   ```bash
   ./addressbook
   ```

   On Windows:

   ```bash
   addressbook.exe
   ```

## 📋 Main Operations

| Option | Operation |
|---|---|
| 1 | Add Contact |
| 2 | Display Contacts |
| 3 | Search Contact |
| 4 | Delete Contact |
| 5 | Exit |
